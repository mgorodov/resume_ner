## Слайд 2: Постановка задачи

**ЦЕЛЬ ПРОЕКТА**  
Автоматическое извлечение структурированной информации из резюме

**ЗАДАЧА**  
Named Entity Recognition (NER) для распознавания:
- Навыков кандидатов
- Опыта работы (компании, должности)
- Образования
- Контактных данных

**ПРИМЕНЕНИЕ**
- HR-отделы: быстрый анализ резюме
- Рекрутинговые платформы: автоматическая каталогизация
- Соискатели: проверка структуры резюме

## Слайд 3: Описание данных

**ДАТАСЕТ:** Resume Entities for NER (Kaggle/Dataturks)

**ОБЪЕМ**
- 220 резюме
- 3,556 аннотированных сущностей
- 11 типов сущностей
- В среднем 16.2 сущности на резюме

**ХАРАКТЕРИСТИКИ**
- Формат: JSON с текстом и аннотациями
- Язык: английский
- Домен: IT-специалисты
- Пропуски: 2 аннотации с пустыми labels (0.05%)
- Найдены перекрывающиеся сущности → очистка данных

## Слайд 5: Метрики качества

**ОСНОВНАЯ МЕТРИКА:** Token-level Accuracy

**ОБОСНОВАНИЕ**
- Оценка корректности классификации каждого токена
- Учитывает схему BILOU (Begin, Inside, Last, Outside, Unit)
- Подходит для задач sequence labeling

**ДОПОЛНИТЕЛЬНЫЕ МЕТРИКИ (планируются)**
- Precision, Recall, F1 по классам сущностей
- Entity-level метрики (полное совпадение границ)

## Слайд 6: Стартовое решение (Baseline)

**ПОДХОД:** SpaCy Blank Model

**АРХИТЕКТУРА**
- Модель с нуля (blank English model)
- Стандартный NER pipeline SpaCy
- 10 эпох обучения

**РЕЗУЛЬТАТЫ**  
**Accuracy: 96.37%**

**ОСОБЕННОСТИ**
- Train/Test split: 90% / 10% (198 / 22 резюме)
- Обработка перекрывающихся сущностей
- Выравнивание границ токенов
